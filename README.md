# Unifi-in-Docker (unifi-docker)

This repo contains a Dockerized version of [Ubiqiti Network's](https://www.ubnt.com/) Unifi Controller.  
It is a fok from [Jacobalberty](https://github.com/jacobalberty/unifi-docker).

I will try and stay up to date with Unifi releases. Currently using Ubuntu 24.04 and MongoDB 7 and Unifi Controller 10.X.
